# 🎯 Personal Introduction Program

## 📌 Project Overview
This is a beginner-friendly Python program that asks the user for their name, age, and favorite hobby. After collecting the input, the program displays a personalized and friendly welcome message using the provided information.

The purpose of this project is to practice basic Python concepts such as user input, variables, and formatted output.

---

## 📚 What I Learned
Through this project, I learned:
- How to use `input()` to take user input
- How to store values in variables
- How to use `print()` for output
- How to use f-strings for formatting
- How to build a simple Python console application
- How to structure a project for submission

## 🧠 Technical Details

This program uses:

- `input()` to collect user information  
- Variables (`name`, `age`, `hobby`) to store values  
- `print()` to display output  
- f-strings for formatted message  

This is a console-based Python application with no external libraries.
