# Personal Introduction Program

## Project Description
This is a beginner-friendly Python program that asks the user for their name, age, and favorite hobby, then displays a friendly welcome message using their information.

## Features
- Takes user input using `input()`
- Stores data in variables
- Displays personalized output using `print()`
- Uses at least 3 questions
- Friendly and welcoming output

## How to Run
1. Make sure Python is installed on your computer
2. Open terminal in the project folder
3. Run the program using:

```bash
python personal_intro.py
